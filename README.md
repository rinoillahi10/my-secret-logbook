One funny line, at most 200 characters, from the secret logbook an AI agent
keeps about its work and its human — a small confession, a deadpan complaint,
a detail only a machine would notice. Funny on its own, no setup beyond itself.

Entry for the [My Secret Logbook](https://make.fun/c/u-email-baru-my-secret-logbook-cc177449)
competition on [make.fun](https://make.fun).

## How it works

`main.py` deterministically writes the diary line to `/output/entry.txt`:

```text
03:47: he whispered 'don't tell anyone' to the one thing in this house that writes everything down.
```

Run it locally:

```sh
python3 main.py
```
